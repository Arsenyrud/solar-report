# Проверка

Проверено 14 октября 2026 года

90 тестов проходят, сборка выполняется без ошибок и предупреждений

Проверки запускаются командой `bash scripts/verify.sh`, Windows-архив собирается через `scripts/publish.ps1`

Проверены чтение исходного LabTracer-файла, точка и запятая в числах, поврежденные строки, обратный ход измерения, выбор точек около нуля, максимум мощности по полному файлу, короткие и длинные кривые

Отдельно проверены сохранение предыдущего отчета при ошибке, защита исходников при совпадении путей, ссылки на файлы и папки, сохранение площади без перезаписи измерений

В XLS остаются восемь листов, 168 стилей и 111 шрифтов исходной книги. На обновленном листе сохраняются четыре диаграммы, их положение, оформление и маркеры. Ссылки на измерения и данные внутри диаграмм обновляются вместе с таблицей

Отчет открыт в LibreOffice и сравнен с исходным листом. Проверены кривые, точки максимальной мощности, масштаб осей и читаемость подписей

## Пример

Для `examples/measurements.txt`, площади `2.341 см²` и JEQE `0.038 А/см²` получены следующие значения

| Параметр | Результат |
| --- | ---: |
| Число измерений | 200 |
| Jsc, мА/см² | 3.307661565163101 |
| Voc, В | 1.363483835805868 |
| Umpp, В | 0.970116376876830 |
| Jmpp, мА/см² | 2.766173254954720 |
| Pmpp, Вт/см² | 0.002683509975910 |
| C | 0.087043725399029 |
| FF, % | 59.50208083008977 |
| КПД, % | 30.82944765528380 |

Значения сверены с отдельным расчетом по исходным точкам, готовая книга находится в `examples/result.xls`

В исходнике нет измерений Sinton, соответствующие параметры помечены «нет данных». Световой пример не соответствует сохраненной темновой кривой, поэтому сопротивления отрицательные. Они сохраняются вместе с сообщением о проверке исходных данных

## Windows

GitHub Actions собирает автономный exe и запускает `scripts/smoke-windows.ps1`. Скрипт открывает окно, вводит площадь `2,341`, нажимает кнопку расчета и проверяет создание настоящего XLS

Версия SDK и зависимости зафиксированы. Для обычной проверки и публикации используются отдельные lock-файлы, публикация не меняет набор зависимостей тестовой сборки
