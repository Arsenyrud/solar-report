# Расчеты

Все точки записываются с третьей строки листа «С=0.7»

| Столбец | Данные |
| --- | --- |
| A | Напряжение, В |
| B | Исходный ток, А |
| C | Время, с |
| D | Напряжение из A |
| E | Плотность тока `-B/H1`, А/см² |
| F | Мощность на единицу площади `D*E`, Вт/см² |

Площадь записывается в H1. JEQE в H4 берется из шаблона или настройки `ReferenceCurrentDensity`

## Выбор точек

Программа ищет смену знака в соседних точках, затем выбирает окно той же длины, что использовалось вручную в исходном листе

| Ячейка | Расчет |
| --- | --- |
| H5 | Среднее 10 значений E около перехода D через ноль |
| I5 | Выборочное стандартное отклонение этого окна, деленное на H5 |
| H6 | `INTERCEPT(D,E)` по трем точкам около перехода E через ноль |
| H7 | `INTERCEPT(T,W)` по двум точкам около перехода W через ноль |
| H8 | `INTERCEPT(M,N)` по двум точкам около перехода N через ноль |
| H9 | `INTERCEPT(K,Q)` по двум точкам около перехода Q через ноль |
| H10 | `INTERCEPT(W,X)` по трем точкам около перехода X через ноль |
| H11 | `INTERCEPT(T,X)` по тем же трем точкам |

Для окна из десяти точек берутся четыре точки перед последней точкой до смены знака и пять после нее. Для трехточечного окна берутся предыдущая точка, последняя точка до смены знака и первая после нее. У границы файла окно смещается внутрь доступных данных

Для световой кривой диапазоны выбираются в направлении возрастания напряжения, в том числе при обратном ходе измерения. В XLS сохраняется исходный порядок строк. Если переходов несколько, используется первый и программа сообщает о необходимости проверить кривую

`INTERCEPT` соответствует функции Excel ОТРЕЗОК: это свободный член линейной регрессии по выбранным точкам. Для трех точек результат отличается от линейной интерполяции только по двум соседним значениям

При коротком файле для усреднения берутся доступные точки, для регрессии нужны минимум три измерения световой кривой. Если световая кривая не пересекает ось напряжения или ось тока, отчет не формируется. Отсутствие нужного пересечения в темновой кривой или Sinton оставляет соответствующий результат недоступным

## Итоговые параметры

Максимум мощности ищется по всем точкам F. При одинаковых максимумах используется первая точка в файле

| Ячейка | Формула |
| --- | --- |
| H14, C | `Jsc/JEQE` |
| H15 | JEQE |
| H16, Eff | `Pmax*10/C`, доля |
| H17, Voc | H6 |
| H18, Jsc | H5 |
| H19, FF | `Pmax/(Voc*Jsc)`, доля |
| H21, Jmpp | E в точке Pmax |
| H22, Umpp | A в точке Pmax |
| H23, Rs_dark | `(H7-H6)/H5` |
| H24, Rs_light_dark | `(H11-H22)/H21` |
| H25, Rs_light_dark_corr | `(H11-H22-(H5-H21)*H23)/H21` |
| H26, Rs_sinton | `(H9-H22)/H21` |

Коэффициент 10 в H16 взят из исходного шаблона: при одном Солнце входная мощность принята равной `0.1 Вт/см²`. Эффективность и FF хранятся как доли, Excel показывает их в процентах

Сопротивления в H23:H26 нормированы на площадь, единица Ом·см². Отрицательные значения сохраняются и сопровождаются сообщением о проверке исходных данных

Темновые данные: T = напряжение, U = ток, V = `U/V2`, W = `H5-V`, X = `H5-H21-V`

Sinton: K = напряжение, L = ток, M = `-L`, N = `K-H6`, O = K, P = `(H8-M)/H8*H5`, Q = `P-H21`, R = `O*P`. H20 считается как `MAX(R)/(Voc*Jsc)`

В исходной книге 200 световых точек, но часть массивов заканчивалась на 199-й. Программа использует одинаковые полные диапазоны для мощности, поиска максимума и диаграмм

В исходнике измерений Sinton нет, поэтому несколько формул возвращали ошибки деления на ноль. В отчете эти места получают «нет данных», остальные расчеты выполняются независимо
