# Использованные материалы

Код программы распространяется по лицензии MIT

Для чтения и записи XLS используется NPOI 2.5.6, лицензия Apache 2.0

- [NPOI](https://github.com/nissl-lab/npoi)
- [Лицензия NPOI](https://github.com/nissl-lab/npoi/blob/master/LICENSE)

Зависимости: SharpZipLib 1.4.2, Portable.BouncyCastle 1.9.0 и библиотеки Microsoft 10.0.13. Тексты лицензий находятся в папке `licenses`

Шаблон и пример измерений получены из [папки с исходными материалами](https://drive.google.com/drive/folders/1-gmNnP1gk5c1Xk5A2JJs5lY5eGFwzd3E)

`templates/template.xls` соответствует файлу «1686-1 Кр16 1 склейка ВАХ.xls», `examples/measurements.txt` соответствует файлу «измерения.txt»

Права на исходные экспериментальные данные и оформление книги остаются у их авторов, лицензия на код программы на эти материалы не распространяется
